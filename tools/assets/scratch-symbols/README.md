# Scratch symbol atlases

Generated with the built-in image_gen tool. Five transparent 3 by 3 atlases contain 45 original pictograms. Each cell is square. PNG originals live here; runtime copies are public/images/scratch-tickets/symbols-1.webp through symbols-5.webp, encoded at original size with Chrome Canvas WebP quality 0.88, preserving alpha. CSS displays one square cell per symbol.

Within each ticket the sorted distinct server numbers receive distinct atlas cells (rotated by the lowest number modulo nine). Equal numbers share one symbol; different numbers never share a symbol. At most eight distinct values occur per ticket. This is presentation only; server results, odds, payouts and saved scratch progress are unchanged.
