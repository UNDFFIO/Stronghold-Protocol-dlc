# Scratch ticket backgrounds

Original UI art generated with the built-in image_gen tool. References: tools/assets/custom-relics/relic_235.png through relic_239.png. PNG originals are stored here; WebP runtime copies ship directly from public/images/scratch-tickets; no asset download or manifest generation is required. WebP copies retain the original dimensions and use Chrome Canvas WebP quality 0.88. All labels, numbers and scratch coatings remain live UI elements.

## tier-1.png

Use case: stylized-concept. Asset type: production background texture for an interactive scratch lottery ticket UI. Use reference image only for its printed paper art style, colors and motifs. Create one flat front-facing rectangular ticket background, landscape 6:5 aspect ratio. Full bleed artwork exactly to image edges, no surrounding scene, no perspective or tilt, no shadow outside. Theme: orange and gold starbursts, cream shooting stars, festive orange waves. Rich finely engraved ink and gold foil printed paper, ornamental perimeter. Keep decoration mostly within outer 7% side/bottom margins and top 20% banner. Large uninterrupted pale warm ivory paper interior from x=8% to 92%, y=23% to 92%, very subtle fine security pattern so dark live UI text is readable. Top banner has decorative motifs clustered at corners, quieter middle for title. NO text, letters, numerals, barcode, scratch panels, silver foil, boxes or UI controls. This is an empty background only, matching reference aesthetics.
